# JekyllEx

[![Загрузки JekyllEx для Android (все файлы, все релизы)](https://img.shields.io/github/downloads/jekyllex/jekyllex-android/total)][github]

[github]: https://github.com/jekyllex/jekyllex-android/releases/latest

JekyllEx — это Android-приложение, которое позволяет управлять блогом на базе [Jekyll](https://github.com/jekyll/jekyll?tab=readme-ov-file#jekyll) непосредственно с вашего Android-устройства!

С момента своего [создания](https://genicsblog.com/introducing-jekyllex-android-app) приложение претерпело значительные изменения: из реализации на основе GitHub API оно превратилось в автономное приложение, которое нативно включает `git`, `ruby`, `jekyll` и другие зависимости, обеспечивая плавный и удобный опыт работы с мощным и простым интерфейсом.

> [!ВАЖНО]
> Старая реализация [архивирована](https://github.com/jekyllex/jekyllex-android/tree/api-impl), а соответствующие релизы больше не поддерживаются!
