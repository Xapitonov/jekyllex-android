JekyllEx — это мощная IDE, разработанная специально для проектов на Jekyll.

Создавайте, просматривайте и публикуйте ваши сайты на базе Jekyll прямо с вашего устройства.

<ul>
    <li>Среда GitHub Pages со встроенными Ruby и стандартными gem'ами.</li>
    <li>Встроенный Git для контроля версий. Легко подключайтесь к своему аккаунту GitHub.</li>
    <li>Мощный интерфейс терминала с поддержкой нескольких сессий. Опыт на уровне настольного ПК.</li>
    <li>Создавайте новые сайты локально или импортируйте существующие из удаленного источника.</li>
    <li>Простое управление файлами и папками. Создавайте, загружайте по URL или из хранилища.</li>
    <li>Встроенный редактор кода с подсветкой синтаксиса. Доступны пользовательские темы.</li>
    <li>Живой предпросмотр для запущенного сервера Jekyll с автоматической перезагрузкой.</li>
    <li>Просматривайте сайт офлайн в любом браузере прямо на устройстве перед публикацией.</li>
    <li>Безопасность по умолчанию. Никаких сторонних бэкендов. Все работает офлайн.</li>
</ul>

Вносите быстрые правки в ваш Jekyll-сайт на ходу в удобном для мобильных устройств интерфейсе.

Посетите <a href="https://jekyllex.xyz">веб-сайт проекта</a> для получения дополнительной информации и документации.
